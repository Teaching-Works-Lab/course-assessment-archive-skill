# 常见错误、校正边界与问答

## 常见错误样例

| 现象 | 判断 | 处理 |
| --- | --- | --- |
| 非试卷课程在教学班根目录放 `02-成绩登记表.pdf`、`03-成绩分析报告.pdf` | 旧结构，不符合 2026 统一规范 | 建 `02-结课考核资料`，按 `03`、`04` 规范命名；移动前预览并确认 |
| 自行增加 `00-课程共用资料`、`01-课程管理` 等，并称为制度必备目录 | 建议性工作区被误写成正式规则 | 可在工作区使用，但正式包按五层与两个第五层分支验收 |
| 考试课使用 `02-结课考核资料` | 课程类型分支错误 | 课程类型已由可靠主数据确认后，改为 `02-期末考试资料` 并按对应清单复核 |
| 非试卷课使用 `02-期末考试资料` | 课程类型分支错误 | 改为 `02-结课考核资料`；不得只改目录名而忽略内部材料差异 |
| 补考包含 `04-试卷分析报告` | 正文明示不提交 | 从提交包排除并保留处置记录；不删除唯一原件 |
| 成绩评定记录表无任课教师签字 | 实质证据缺口 | 退回任课教师补正，任何上级不得代签 |
| 附件截图出现 DOCX/XLSX，因此正式包也保留这些格式 | 把示例工作状态当成正式格式 | 正式归档转为 PDF，源文件另行受控保留 |
| 专业代码存在空号便自行顺次重排 | 错误 | 附件 2 是受控对照表，忠实使用，不把空号当数据库错误 |
| 只检查一个教学班就宣布课程、专业或学院合格 | 覆盖范围错误 | 建立下级对象清单；逐项关闭后才能给上级整体结论 |
| 把示例中的张三、示例班级或课程代码用于真实目录 | 示例身份污染 | 只使用真实主数据；信息缺失时报告无法建立正式路径 |

## 自动校正分级

### 可以形成预览，确认后执行

- 父级课程目录能够唯一给出公共前缀时，补全第四层缺失的课程前缀；
- 课程考核类型已经由可靠主数据确认时，纠正第二分支名称；
- 文件内容和课程名称明确时，修正固定编号与规范文件名；
- 将补考 `04-试卷分析报告` 移出提交包并记录去向。

每次必须保存改前路径、改后路径、依据和复核结果。批量操作先小样本验证。

### 只能报告并退回

- 缺少或无法确认签字；
- 成绩、统计、评分记录或学生样本缺失、冲突；
- 课程类型、课程代码、班级、教师等主数据不明确；
- 需要修改 PDF 内实质内容；
- 多个目标都可能正确，无法唯一改名或移动。

## 问答合同

回答先说明角色和检查范围，再按以下三类写结论：

- **文档明确支持**：可给确定结论，并指出正文条款、附件或本地来源页；
- **合理解释**：说明推理链，并明确不是原文逐字规定；
- **无法确定**：指出缺少哪份制度、主数据或文件，不用常识填空。

推荐输出：

```text
目标目录树或“现有文件 → 完整相对目标路径”表：
角色与范围：
结论：合格 / 不合格 / 有条件合格 / 无法判断
必须整改：
待核实：
谁处理、谁复核：
可安全自动处理：
依据及证据等级：
```

## 常见问答

### “我是任课教师，我到底交什么？”

站在第四层教学班位置回答：先确认课程类型；所有课程交 `01-过程性资料`，试卷课程另交 `02-期末考试资料`，非试卷课程另交 `02-结课考核资料`。第一部分直接给可复制的目标树；未知主数据保留占位符。例如非试卷课程：

```text
<学院批次>/<专业>/<结课周数-课程代码-课程名称>/<结课周数-课程代码-课程名称-教师-班级>/
├── 01-过程性资料/
│   ├── 教学大纲.pdf
│   ├── 成绩评定记录表（签字版）.pdf
│   └── <大纲实际采用项的要求、评分标准和学生样本>.pdf
└── 02-结课考核资料/
    ├── 03-成绩登记表-<课程名称>.pdf
    └── 04-成绩分析报告-<课程名称>.pdf
```

再说明第一至第三层主数据由上级确认，教师仍要核对路径；不能用示例值替换真实数据。

### “我是教学秘书，怎么判断专业收齐了？”

建立“课程负责人目录 × 任课教师 × 教学班”覆盖清单，逐包核对路径、分支、证据和格式。教学秘书可以向下发现并登记教师层问题，也可处理无歧义的结构性错名；签字、评分、学生证据和课程内容问题退回责任人，复核关闭后再向学院汇总。

### “学院抽几门课没有问题，能不能宣布合格？”

不能。抽查只支持“已抽查对象未发现问题”，不支持未检查对象或整个专业合格。

### “A/B 卷的试题和答案必须合成一个 PDF 吗？”

无法从当前文件确定唯一物理封装方式。正文把每套样卷描述为“试题及参考答案”，附件截图展示同号试题和答案文件。可以确认它们必须组成完整逻辑包，不能断言必须合并或必须拆分。

### “校字〔2026〕71号是否废止校字〔2025〕141号？”

当前无法确定。2026 归档规范引用 71 号，但本地未持有其原文和废止条款。只能说现行归档结构以教通字〔2026〕2号为直接依据。

### “附件3是不是把所有‘考试’都替换成‘考查’？”

不是。附件 3 只明确五项转换，其中字段是“考试形式：闭卷”改为“考核形式：考查”。不得做全文机械替换，也不得改统计数据。

### “对方问了制度没有规定的问题怎么办？”

只回答已经得到支持的部分；其余标为合理解释或无法确定。不要因为对方是领导、催得急或要求肯定答案，就把惯例、旧文件或附件示例升级为现行制度事实。
